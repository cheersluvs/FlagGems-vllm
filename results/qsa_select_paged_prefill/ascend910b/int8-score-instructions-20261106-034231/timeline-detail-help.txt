msopprof (MindStudio Profiler For Operator) is part of MindStudio Operator-dev Tools.
Used for Ascend C operator profiling by running on the board.

Options:

  -v, --version                             Show version information.
  -h, --help                                Show help message.
      --config=<FILE>                       Json file for op config path.
      --application=<FILE>                  Executable file path.
      --output=<PATH>                       Output path.
                                              PATH:default "./"
      --aic-metrics=<TYPE>                  Enable collection ability type:
                                              TYPE:ArithmeticUtilization | MemoryUB | Memory | MemoryL0 | L2Cache |
                                                | PipeUtilization | ResourceConflictRatio | Default | BasicInfo | Roofline |
                                                | Occupancy | TimelineDetail | KernelScale | Source | MemoryDetail |
      --kernel-name=<NAME>                  Specify the kernel name to profile.
                                              Not effective in config mode.
      --launch-count=<LIMIT>                Number of kernel that can be collected.
                                              LIMIT:1-5000, default: 1
      --launch-skip-before-match=<SKIP>     Set the number of kernel launch to skip
                                              before starting to analyze the kernel.
                                              SKIP:0-1000, default: 0
      --replay-mode=<MODE>                  Data collection replay mode.
                                              MODE:application|kernel|range, default: kernel
      --kill=<SWITCH>                       Kill op process when the number of kernel reaches launch-count.
                                              SWITCH:on|off, default: off
      --mstx=<SWITCH>                       Enable mstx API or not.
                                              SWITCH:on|off, default: off
      --mstx-include=<RANGE>                Specify the mstx range for msprof op to be collected.
      --warm-up=<TIMES>                     Set the number of warm up times.
                                              TIMES:0-500, default: 5
      --dump=<SWITCH>                       Enable or disable dump flushed to disk mode. Only effective when
                                              --aic-metrics=<TIMELINEDETAIL>.
                                              SWITCH:on|off, default: off
      --core-id=<ID>                        Specify the id of cores to be parsed.
                                              Only effective when --aic-metrics=<TIMELINEDETAIL> and only
                                              effective in simulation products.
      --custom-input=<FILE>                 Json file for op custom input.
