# Fixed512 sort from existing TLE primitives

| Project truth | Contract |
| --- | --- |
| Goal | Replace only generic local sort scheduling with fixed512 TLE composition |
| Frozen | Block512 Cube,query16,two slots,masks,online history merge and final output,compiler/bitcode |
| Editable | Diagnostic TLE source,probe flag,installed primitive capture and CPU tests |
| Evidence | Prior explicit sort buffer lifetime experiment passed poison checks but delivered only0.06-0.10% micro gain; not retained |
| Timing | Three matched prepared fixtures,two interleaved rounds; no CANN or full-input acceptance claim |
| Integration | No production registration,autotune or FlagTree/compiler/native custom-op modification |

| Contract | Value |
| --- | --- |
| generic | Original sort_1d_pack,impl0,descending,TOPK512 |
| fixed | sort32 repeat16;mrgsort32-to128 repeat4;mrgsort128-to512 repeat1 |
| Format | Same1024 FP32 words interleaving score/index bits; global index offset block*512 |
| Merge | Four valid ways,exhaustion disabled,proposal offsets not float-word offsets |
| Ordering | Explicit debug barriers between local primitive stages and before history consumes the final packed tensor |
| Buffers | Three1024-word ordinary output tensors; no uninitialized-buffer candidate from preceding probe |
| Validation | Independent CPU sort-network plan plus exact trace,ranked scores,guards and task counts on device |
| Boundaries | Zero/partial/full visibility,masked key tails and multi-query row tails |

| Path | Behavior |
| --- | --- |
| --tle-sort512 | Requires raw-mixed-online,boundaries,cube-block512; excludes other diagnostic variants |
| Source capture | Installed registry,sort32,mrgsort,generic source,bitcode hash and LLVM excerpts |
| Compile gate | Generic retains sort_1d_pack;fixed retains one sort32 and two mrgsort calls,without generic local sort |
| Scope | Operator-layer composition of existing public primitives; no new native implementation |

Local validation:71 raw/ABI/boundary/aggregation/network checks plus five
complete-input schedule checks passed. The network model executes the generated
primitive-call fragment with counting/layout stubs,checks all512 values and
offset indices against an independent full sort across ties,all-invisible,
ascending/reverse,large and masked inputs. This verifies the declared repeat
layout,not hardware semantics. Generic IR gate also passed all three previous
actual baseline artifacts. Python compilation,Bash syntax,focused pre-commit
and diff checks passed. NPU correctness and performance remain pending.
